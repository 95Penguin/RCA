# 粗细粒度修正：移除系统头的原始偏差直连

## 修改的依据与范围

此前事后诊断发现，系统头直接读取加权原始偏差在部分折中有不良影响。该观察不能替代从头训练的消融。本轮只修改这一处，不引入新门控、损失或监督定义。

保留三模态时序编码、模态融合、图层、服务级证据、全局上下文查询和 RCA 头。新模型名为 `joint-granularity-encoded-local`；旧模型名与默认行为保持兼容。

```text
历史三模态 → 时序编码 → 融合与图交互 → 全局上下文 g
指标时序表示 + 原始正常偏差 → 服务级表示 E_i
g 查询 E_i → 加权服务表示 → 与 g 拼接 → 下一分钟系统预测
E_i + 图后服务表示 + g + 原始偏差 → 根因服务排序
```

旧系统头输入 `[g, selected E, selected deviation]`；修正版使用 `[g, selected E, 0]`。保留偏差槽位使参数形状、参数量与初始化顺序完全一致。服务级表示内部仍使用偏差，系统损失仍可更新服务编码器；RCA 的直接偏差路径保留。训练与推理使用相同掩码，不是训练完成后按测试折选择屏蔽。

全部神经网络从随机初始化训练，无冻结、无 detach、无旧模型分数残差。根因概率未被当作系统故障概率。

## 实验协议

OB / TT 各 deployment 五折，seed 42，history 5，精确下一分钟状态，30 epochs、batch 64、AdamW lr 0.001。系统加权 CE + 0.5 事件平衡根因排序 CE，node BCE=0。两个任务的结果均来自验证 AP 选择的一份完整 checkpoint。参数量均为 162,503，LTFP 为 139,591。

对照复用上一轮已完成的同协议运行；本轮重训原 Joint 的 OB fold0，AP、MRR 与完整 30 轮验证轨迹逐项完全复现。检查新旧训练/验证/测试窗口数、事件权重、损失权重与评估事件数一致。

正常参考仍沿用训练折系统标签为负的窗口。这不保证服务局部健康；本轮未改变参考定义，以避免混入第二个实验变量。

## 判断与限制

- OB 相比原 Joint：AP +0.066994；MRR +0.034158。
- TT 相比原 Joint：AP +0.025104；MRR +0.026463。

两数据集的五折平均 AP 与 MRR 都高于原 Joint，说明这个连接方式值得修正；但它没有解决全部问题：修正版 AP 在 OB / TT 仍低于同设置 LTFP，差值分别为 -0.025288 / -0.014330。MRR 高于同设置 LTFP，分别为 +0.024226 / +0.048203。不能称为两个任务均已超过基线。

逐折收益并不一致：AP 在 OB 为 4/5 折提高、TT 为 3/5 折提高；MRR 在 OB 为 3 升/1 降/1 平，TT 为 2 升/1 降/2 平。保留修正版作为下一阶段候选，旧版本和默认运行设置均保留；本轮不继续更换多个模块或按测试结果调整损失。

这是已查看过测试折后的探索性修正，不能作为未触碰测试集的独立确认。只有一个随机种子；跨折标准差不是多随机种子的稳定性证据。未按测试折切换模型或阈值，未按测试指标挑选 checkpoint。

事件 MRR 对同一事件可用窗口做回顾性平均，不等于故障前已定位正确。

历史更强 LTFP 结果仍应保留：OB AP/MRR 约 0.918803/0.878226，TT 约 0.845770/0.931667；其训练设置不同，不能被本轮较低的配对对照替代而宣称领先。

本轮是结构诊断与修正，不构成方法新颖性或发表可行性的证明。具体是否继续采用修正版本应同时查看 AP 与 MRR，不只选择改善的一项。
