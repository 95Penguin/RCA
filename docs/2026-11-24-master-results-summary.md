## 0. 窗口级 vs 事件级：区别与选择

**窗口级**：每个正例的 5 分钟滑窗是一个样本，先对每个窗口排一次名，再对所有窗口求平均。
**事件级**：先按 `event_id` 把同一故障事件的窗口分组，组内服务分数取均值，每个事件只排一次名，
再对所有事件求平均。

两者的差别不是“谁更严格”，而是回答不同的问题：

| | 窗口级 | 事件级 |
|---|---|---|
| 样本单位 | 窗口（455/436） | 事件（55/64） |
| 回答的问题 | 每一分钟的输出对不对 | 每一次故障事件有没有找对根因 |
| 长事件的影响 | 长事件权重大 | 每个事件等权 |
| 独立性 | 同一事件的窗口高度相关，存在伪重复 | 事件近似独立，CI 更可信 |
| 适合 | 在线逐分钟稳定性、与既有窗口级工作对比 | 论文主结论、显著性检验 |

同一批预测在两种口径下的差异（本仓库实测）：

| 数据集 | 方法 | 窗口级 H@1/MRR | 事件级 H@1/MRR |
|---|---|---|---|
| OB | CPCA | 0.868 / 0.930 | 0.855 / 0.920 |
| OB | LTFP | 0.827 / 0.896 | 0.782 / 0.874 |
| OB | CIRCA | 0.793 / 0.848 | 0.727 / 0.808 |
| TT | CPCA | 0.958 / 0.979 | 0.953 / 0.971 |
| TT | LTFP | 0.852 / 0.903 | 0.875 / 0.923 |
| TT | TVDiag | 0.686 / 0.782 | 0.781 / 0.850 |
| TT | CIRCA | 0.460 / 0.600 | 0.562 / 0.671 |

方向并不固定：OB 上窗口级普遍略高，TT 上事件级反而更高。原因是事件内窗口数不同，
窗口级会被长事件拉高或拉低；因此**不能把两种口径混在一张表里比较**。

**写论文的建议：**

1. **主表用事件级**。根因定位的决策单位是“一次故障事件”，不是“一分钟窗口”；
   事件级避免伪重复，55/64 个独立样本的置信区间才可信。
2. **附录放窗口级**，并明确写“窗口级、用于与已有窗口级工作报告对比，不用于显著性结论”。
   本仓库的 140 次 specialist 原始报告就是窗口级，必须保留可复现的对照。
3. **显著性检验按事件聚类**：即使主表用窗口级，bootstrap 也必须按 `event_id` 重采样，
   不能把 455 个窗口当独立样本。
4. **每张表标注**：`窗口级/事件级`、`n=55/64 事件`、`F1 阈值口径`。
5. **本项目的具体做法**：14 个 baseline 的 `predictions.jsonl` 都有 per-window `root_scores`，
   所以已经全部重算成事件级（第 3 节）；主表直接用第 3 节，第 2 节作为附录。

## 4. 关键结论

1. **预测**：OCSID 的 AP 在 OB 为 0.966、TT 为 0.866，均高于所有 baseline；
   校准 F1 0.899/0.781，也都是最高。
2. **定位（窗口级）**：CPCA 在 OB 0.868/0.930、TT 0.958/0.979，均为最高；
   CIRCA 在 OB 很强（0.793/0.848）但在 TT 崩到 0.460/0.600，
   TVDiag 在 TT 较强（0.686/0.782）但在 OB 只有 0.547/0.711；CPCA 是唯一两边都稳的。
3. **定位（事件级）**：CPCA 0.855/0.920（OB）、0.953/0.971（TT），均高于 LTFP 的
   0.807/0.878、0.894/0.932。
4. **图类 baseline 的定位普遍弱**：GCN-GRU 0.390/0.631（OB）、0.374/0.593（TT），
   InstantOps 0.281/0.472、0.205/0.309；这与“图传播稀释根因局部证据”的动机一致。
5. **学习式 RCA 头不如 CPCA**：OCSID 学习头窗口级 0.768/0.855、0.882/0.925，
   与 CPCA 融合也没有增量（λ 单调趋近 CPCA-only）。

## 5. 口径与可比性

- 所有 baseline 为 seed 42；GRU/GCN-GRU 为 42/123/2026；OCSID 为 42/123/2026。
- baseline F1 用各折验证集最大 F1 阈值；OCSID 的“校准 F1”同协议，两者可比；
  OCSID 原始 F1@0.5 不用于这张表。
- 第 2 节为窗口级 RCA（与 140 次 baseline 原始报告一致）；第 3 节为事件级。
- 第 3 节的 baseline 事件级不是原始报告里的数字，而是用各自的 `predictions.jsonl`
  重新聚合得到的（n=55/64 事件），因此和 CPCA/OCSID 可直接比较。
- CPCA 窗口级覆盖 401（OB）/383（TT）个正例窗口，覆盖率约 90%；未覆盖窗口回退学习头。
- **仓库有两套 LTFP，不能跨表比较**：
  - `ltfp-suite`：`comparison_2026-11-19` 里的适配版，用于第 1 节预测和第 2 节窗口级 RCA；
  - `LTFP`：`re2_next_minute_all_baselines` 的正式版，用于第 3 节事件级 RCA。
  两套的 F1 阈值口径（验证阈值 vs 0.5）和实现都不同；论文主表应固定一套，另一套放附录。
- baseline 是统一任务下的适配版本，不是作者原论文原任务的精确复现。
- 事件数少（55/64），主表仍需补配对 bootstrap。
