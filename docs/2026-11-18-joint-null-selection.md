# 粗细粒度交互：允许不采用局部证据的注意力实验

## 本轮假设与修改

当前 encoded-local 模型仍对 N 个服务做 softmax，服务权重和恒为 1。本轮只增加一个零值空选项，让系统上下文可以减少服务级输入。不将该权重直接解释为故障概率或经过校准的证据可靠性。

新模型名：`joint-granularity-null-selection`。保留三模态 TCN、模态融合、图交互、正常参考、服务证据编码、RCA 头、两任务损失及验证 AP 选模规则。关闭原始偏差到系统头的直连，与 encoded-local 对照一致。

```text
q = Wq g，服务分数 s_i = q·Wk E_i / sqrt(d)
空项分数 s_0 = q·k_0 / sqrt(d)，k_0 为可学习的 64 维零初始化参数
[a_0,a_1,...,a_N] = softmax([s_0,s_1,...,s_N])
z = sum_i a_i E_i，空项的值固定为零，不重新归一化服务权重
系统预测 = Head_F([g,z,0])
RCA = 原来的服务级最终排序头
```

空项只存在于内部注意力中，未改成 N+1 类故障/根因联合分类。两个输出保持独立语义。同一完整模型随机初始化并端到端训练，没有冻结或 detach。新模型参数量 162,567，对照 162,503，增加 64 个参数；未声称参数量完全匹配。共有参数初始化一致，测试已验证。

## 实验协议

OB / TT 各 deployment 五折，seed 42，history 5，精确下一分钟状态，30 epochs、batch 64、AdamW lr 0.001；系统类别加权 CE + 0.5 事件平衡根因排序 CE。两个任务从验证 AP 选择的同一个 checkpoint 输出。

本轮新训练 10 组空选项模型，复用上一轮完整配对对照。另重训 encoded-local 的 OB fold0，AP、MRR 和完整 30 轮验证轨迹逐项完全复现。检查新旧划分窗口数、损失权重、事件权重、评估事件数及原始输入 SHA256 一致。

## 判断与限制

- OB 相比当前修正版：AP -0.019448，MRR -0.000545。
- TT 相比当前修正版：AP -0.015281，MRR -0.021991。

本轮不采用空选项版替换 encoded-local：两个数据集的平均 AP 均下降，OB MRR 基本持平，TT MRR 下降。当前候选仍为 encoded-local；空选项版仅保留为可复现的研究对照，不改变原有默认模型选择。

从权重看，9/10 折的测试窗口均未出现空项权重达到 0.5；OB fold0 也只有约 1.4% 的窗口达到该值。多数折的空项权重很小，未观察到跨折一致的明显拒绝行为；这不代表它完全没有通过软权重改变局部输入，也不能据此断言下降的唯一原因。

TT fold4 的空项版按验证 AP 选中第 2 轮，而 encoded-local 选中第 20 轮；该折 AP 上升但 MRR 下降。RCA 训练进度与选模取舍值得留意，但本轮不据此按测试 MRR 改选 checkpoint。

同一 seed 的五折属于探索性结果，测试折此前已被查看，不能作为独立确认。没有按测试折切换新旧模型、改变阈值、挑选 checkpoint 或调节损失。空项权重由系统预测损失间接学习，没有可靠性真值监督；数值本身不能证明根因证据正确或存在因果影响。

事件 MRR 对同一事件的可用窗口分数做回顾性平均，不等于故障前已经定位正确。

历史更强 LTFP 参考仍保留：OB AP/MRR 约 0.918803/0.878226，TT 约 0.845770/0.931667，训练设置与本轮配对对照不同。不能仅用较低的同设置对照宣称方法领先。
